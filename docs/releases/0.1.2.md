# hivenal 0.1.2

Released 2026-10-16. For macOS on Apple Silicon and Intel. To install, update or uninstall, see the README.

## Changes

- The first run after a Homebrew install works again. In 0.1.1, Homebrew moved `LICENSE` out of the installed
  files, so the first `hivenal` command stopped with `file listed in MANIFEST.sha256 is missing: LICENSE`.
  0.1.2 keeps the file in place.
- Every release is now checked with a real first run from the Homebrew install on both architectures.
- The formula and `hivenal update --published` download release files from GitHub's release download links,
  without a token.

## If you installed 0.1.1 with Homebrew

The 0.1.1 formula was withdrawn on 2026-10-15; 0.1.1 stays a prerelease. On a 0.1.1 Homebrew install every
`hivenal` command except `hivenal --version` fails. We expect these commands to move it to 0.1.2:

```sh
brew update
brew upgrade hivenal
hivenal release verify
```

We have not tried them on a Mac that still has the 0.1.1 install. If `brew upgrade` does not offer 0.1.2 or
`hivenal release verify` fails, run `brew uninstall hivenal`, install again as the README describes, and then
run `hivenal release verify`.

If you made 0.1.1 start by copying `LICENSE` back by hand, we expect that `hivenal --version` may still show
0.1.1 after the upgrade. This command should then select 0.1.2; we have not tried it on such a Mac:

```sh
"$(brew --prefix hivenal)/bin/hivenal" update --bundle "$(brew --prefix hivenal)/libexec"
```
